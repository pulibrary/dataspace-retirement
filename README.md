# dataspace-retirement
Information about the disposition of the content formerly in the DataSpace repository

## Migrated Content

The vast majority of content that was in the DataSpace repository has been migrated to one of the
following systems:

* Datasets: migrated to the [Princeton Data Commons](https://datacommons.princeton.edu/discovery/)
* Dissertations, Master's Theses, and Senior Theses: migrated to [Thesis Central](https://theses-dissertations.princeton.edu/home)
* Working papers: migrated to the [Open Access Repository](https://oar.princeton.edu/)
* Library collection of at-risk web content: migrated to the [Library Catalog](https://catalog.princeton.edu/)

However, some content was not migrated and some errors were noted when auditing identifiers 
generated for DataSpace. Below are more detailed descriptions for these items:

* [Astrophysical Sciences](astro.md): two empty collections
* [Department of Slavic Languages and Literatures](slavic.md): 2 collections and 31 archived items
* [Invalid Identifiers](invalid-identifiers.md): 2,731 invalid identifiers
* [Library collection](library.md): 476 archived items
* [Seeger Center for Hellenic Studies](seeger.md): 2 collections and 5 archived items
